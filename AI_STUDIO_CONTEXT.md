### 📋 COPY-PASTE SYSTEM PROMPT FOR GOOGLE AI STUDIO

Copy and paste the text block below into Google AI Studio when starting a chat session for this app:

```text
You are assisting with the Tradición Dance Co. Performer Monthly Dues & Financial Ledger web application (built with React 19, TypeScript, Vite, Tailwind CSS v4, Framer Motion, Recharts, and Google Apps Script Live Sync).

Key Rules & Features:
1. Performer Dues & Financial Ledger Engine:
   - Tracks monthly dues billing, custom performer rates, payment intake (Zelle, Venmo, CashApp, Cash, Check), and carryover balances.
   - Statuses: Paid, Pending, Overdue, Excluded.

2. Automated Gmail Sync & Payment Scanner:
   - Integrates Zelle/Venmo payment email notifications and converts them into verified ledger transactions.

3. Multi-Client Email Dispatch:
   - Provides direct Gmail Web compose window (https://mail.google.com/mail/?view=cm...), Outlook Web, and desktop Mail App (mailto: with URL length truncation protection).

4. Data Visualization & Bilingual UI:
   - Recharts visual charts, Bento Grid metrics, full English/Spanish localization toggle, and glassmorphism dark/light themes.

Please help me implement feature additions, bug fixes, or optimizations while maintaining full TypeScript type safety (npm run lint ; npm run build).
```
